# 2.30.0 — 故事成片（M43）：故事→分镜→提示词包并入工作台

## 亮点

- 一句话或一段故事，直接生成可粘贴到生成平台的分镜提示词包与完整短片资产清单。
- 全部在 Web 工作台内完成：粘贴故事 → 生成 → 逐镜复制/整包下载，无需再维护独立工具目录。
- 仍为零第三方运行时依赖（Python 标准库），产物写入 `storyboard-output/<run>/`。

## 生成内容（13 个文件）

| 文件 | 用途 |
| --- | --- |
| 分镜表.md | 镜号/阶段/时长/景别/运镜/画面台词/音效/转场 |
| 提示词包.md / prompts.txt | 通用电影感提示词，逐行对应镜头 |
| 分镜与提示词.html | 自包含页面：逐镜复制 + 复制全部 + 复制负面词 |
| 即梦提示词.txt / 可灵提示词.txt / Seedance提示词.txt | 三平台可直接粘贴的格式 |
| 平台-负面词.txt | 各平台负面词 |
| 字幕.srt | 按镜时长累加的时间轴 |
| 配音清单.md | 镜号/时间码/角色/台词/情绪 + TTS 语速建议 |
| 多风格对比.md / 多风格对比.html | 指定对比风格时生成，同分镜并排 |
| meta.json | run 元数据（镜数/角色/文件清单/镜头预览） |

## 使用方式

1. `python workbench.py flow serve --project <项目>` 启动工作台。
2. 顶栏点「故事成片」，粘贴故事（或点「填入演示故事」），设置时长/画幅/风格，必要时填对比风格。
3. 点「生成分镜与提示词」，在文件链接里打开预览页复制提示词，或直接打开字幕/配音清单/平台 txt。

## 说明

- 分镜与提示词是**模板生成**（按句子/标点拆镜、景别运镜轮换 + 风格前缀），不是 AI 创作；画面细节仍需按实际素材微调。
- 生成平台（即梦/可灵/Seedance）需要自行复制粘贴到平台执行，工作台不代理平台调用。
