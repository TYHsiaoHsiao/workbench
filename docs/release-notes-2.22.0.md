# workbench 2.22.0 发行说明（M35：批次报表 HTML 化）

## 新增

- `flow batch-report --format html [--out batch-report.html]`：生成**自包含 HTML 报告**（内联 CSS，无外部资源），包含汇总卡片（批次/图运行/成功率/平均耗时）、成功/失败趋势条与明细表。
- Web：`GET /api/batches/report?project=<项目>&limit=20&format=html`；批次历史面板新增「报表 HTML」按钮（浏览器直接下载 `.html`）。
- Web 面板原有「报表 MD / 报表 CSV / 报表预览」保持不变。

## 验证

- 全量 513 项测试通过（新增 1 项 HTML 报表测试）。
- 行覆盖率 81.13%（6965/8585 行），分支覆盖率 51.49%（3282/6374 条分支），CI 双门槛通过。
- 发行包冒烟、可复现构建、回滚演练 `2.21.0 → 2.22.0 → 2.21.0` 均通过。

## 兼容性

- 契约无变化；新增 `html` 输出格式与只读端点参数，默认行为不变，向后兼容。
- 报表仍为只读快照（最多 20 个批次），HTML 不写入项目目录（由用户 `--out` 或浏览器下载决定落点）。
