# 发行说明 2.0.1 — 实时预览与界面迭代（PATCH）

- 版本：2.0.1（PATCH，无契约与 CLI 行为变更）
- 日期：2026-11-15

## 新增能力

- 实时预览：`GET /api/dev/version` 返回内置静态资源签名（`filename:size:mtime_ns` 与 `latest_mtime_ns`）；前端每 1.2s 轮询，检测到变更后提示并整页刷新，状态栏显示「● 实时预览」。
- 界面迭代：节点按分类着色（分类圆点 + 同色类型徽标）、端口连接圆点、贝塞尔箭头连线与悬停高亮。
- 演示内容：预览演示项目新增「17 类节点演示」流程图（17 节点 / 26 连线，覆盖全部节点类型）。

## 验证

- 新增 2 项 Web API 测试：dev 版本端点结构、静态文件变更后签名变化；全量 325 项通过。
- 手动验证：`flow serve` 后修改 `style.css`，1–2s 内页面自动刷新，服务端日志出现 `GET /api/dev/version` 轮询。
- CI 全绿（compile / tests / doctor / brand-guard），品牌守卫 0 命中。

## 限制

- 实时预览为整页刷新，会重置缩放与选中状态；仅跟踪 3 个内置静态资源。
- 后端 Python 改动不会热更新，需重启 `flow serve`。
- 未实现多客户端同步与文件级热替换（后续可评估）。

## 兼容性

- 无 schema、state、CLI 参数或 Web API 兼容性变化；插件式客户端无需改动。
