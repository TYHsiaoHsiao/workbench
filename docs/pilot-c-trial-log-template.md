- ¹ **人工步骤数**：该阶段你手动执行的命令次数（init/route/gate/reference/apply/inject/export 等），不含纯聊天。
- ² **门禁是否拦停**：`是` = 有门禁阻止推进且你需要补齐；`否` = 一次通过。拦停时在备注写门禁 id。

辅助命令（需要时）：

```bash
python workbench.py gate list --project <项目名>      # 看缺哪道门禁

python workbench.py export --project <项目名>         # 每周留档一次
```
