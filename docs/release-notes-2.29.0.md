# workbench 2.29.0 发行说明（M42：全 Web 化）

> 日期：2026-11-17 ｜ 类型：MINOR（向后兼容） ｜ 契约版本：v1.0（无变化）

## 能力

- **操作台扩充到 44 个白名单操作**：在 24 个基础上新增 20 个创作主线操作——创建项目、一键开工（不写演示素材）、意图路由、门禁查看与通过/失败/豁免、推进阶段、流程图新建/列表/运行/运行记录、风格库列表/查看/应用/注入、产物登记、参考记忆列表、项目导出、生成任务列表/重试/回填。
- **操作历史落盘**：每次执行写入 JSONL（默认 `~/.workbench/ops-history.jsonl`，可用 `WORKBENCH_OPS_HISTORY` 覆盖），重启后加载最近 50 条。
- **操作搜索过滤**：操作台侧栏搜索框按名称/ID/分类/描述过滤。
- 状态变更操作（推进阶段、写门禁）带确认文案，避免误操作。

## 验证

- 全量 `Ran 548 tests ... OK`；新增 2 项（注册表覆盖 40+ 操作、历史落盘与重载）。

## 使用

```bash
python workbench.py flow serve --project 预览演示 --port 8899
# 浏览器打开后点顶栏「实操指引」→ 操作台；左侧搜索操作，右侧填参数执行
```
